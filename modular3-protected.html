MedControl — защищённый режим

Отдельное хранилище. Действующие записи не изменяются.

Хранилище уже существует. В поле «Локальный пароль» введите прежний пароль входа. Новый пароль, заданный при создании файла, введите ниже. Для сверки выбранного файла без изменений нажмите «Проверить готовность переноса». До переноса прежнее хранилище будет сохранено отдельной зашифрованной копией.

Эти копии открываются паролем, действовавшим до соответствующего переноса.
