# 95 Interface Languages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 95 usable offline interface catalogs throughout protected MedControl.

**Architecture:** Preserve existing handlers, extend translation lookup, and replace only presentation literals. Cache the catalogs and save chosen language through encrypted settings.

**Tech Stack:** Existing plain JavaScript, static JSON/JS catalogs, Node/Python build checks, Playwright.

**Spec:** docs/superpowers/specs/2026-10-24-95-languages-design.md

## Global Constraints
- Stay on modular-3.000. No real-data, Production, Supabase or Microsoft operations.
- UI text only; retain medical values, history, time zone and factual timestamps.
- Archive permits viewing and explicit reset only. No new course behavior.

## Review Focus
- A medication name identical to a UI label must remain unchanged.
- RTL must preserve left-to-right numeric inputs, passwords and timestamps.
- Saved language must survive offline relaunch and failed settings writes.
- Changing language while a draft/dialog exists must not lose entered values.
- Missing catalogs/keys must fail readiness/coverage checks rather than masquerade as 95 translations.
