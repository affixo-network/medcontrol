# MedControl — смысловые аннотации действий (эталон RU)

Статус: согласуемый справочный эталон для локализации на 95 языков. Аннотации не заменяют перевод кнопок и не изменяют поведение программы. До публикации на других языках требуется проверка смысла в контексте.

## Общие правила
- MedControl регистрирует действия пользователя и события расписания, но не назначает лечение и не подтверждает фактический приём препарата.
- «Принято» означает, что пользователь отметил совершённый приём; время отметки фиксируется как фактическое время.
- «Не принято» означает отсутствие подтверждённой отметки о приёме, а не медицинский запрет принимать препарат.
- «Случайное нажатие» и «Ошибка» — разные согласованные формулировки. Нельзя подменять одну другой.
- Сохранение, отмена и восстановление не должны описываться как успешные до фактического подтверждения системой.

## Ввод
| Действие / понятие | Что пользователь должен понимать |
|---|---|
| Препарат | Название средства, для которого ведётся расписание и журнал приёмов. |
| Производитель | Сведения об изготовителе препарата; не являются назначением лечения. |
| Количественное содержание (указанное производителем) | Содержание вещества в указанной единице препарата; не равно количеству на один приём. |
| Единица содержания | Единица, в которой указано количественное содержание. |
| Количество приёма | Сколько единиц препарата запланировано на один приём согласно назначению врача; не равно содержанию вещества. |
| Единица приёма | Единица количества, используемая в расписании приёма. |
| Расписание | Правило, по которому MedControl рассчитывает запланированные даты и часы. |
| Каждый день | Запланированные приёмы повторяются ежедневно в пределах дат курса. |
| Каждую неделю | Запланированные приёмы повторяются по выбранным дням недели в пределах курса. |
| По датам | Приёмы запланированы на указанные календарные даты. |
| Добавить время | Добавляет ещё одно плановое время в расписание; само по себе не подтверждает приём. |
| Сохранить | Запрашивает сохранение введённых данных; успешность определяется сообщением системы. |
| Изменить | Редактирует выбранные параметры; история изменений должна сохраняться по правилам приложения. |
| Начало и конец курса | Определяют календарные границы расписания, а не медицинское заключение. |
| Активно / Пассивно | Режим работы курса в интерфейсе; не означает изменение врачебного назначения. |

## Приём препаратов
| Действие / статус | Смысл |
|---|---|
| Ожидается | Запланированный приём ещё не отмечен как совершённый. |
| Принято | Пользователь подтверждает, что препарат был принят; система записывает отметку и фактическое время нажатия. |
| Не принято | Нет подтверждённой отметки «Принято» для данного планового приёма. Это не инструкция пропустить препарат. |
| Принято позже | Отметка сделана после расчётного времени; это описание записи, не медицинская оценка. |
| Отмена «Принято» | Отменяет ошибочную отметку, а не физический факт приёма препарата. |
| Случайное нажатие | Причина отмены: пользователь случайно нажал кнопку отметки. |
| Ошибка | Отдельная согласованная формулировка ошибки; её значение зависит от конкретного доступного действия и не должно обещать изменение времени. |
| Расчётное время | Время, рассчитанное по расписанию. |
| Фактическое время | Время зафиксированного действия пользователя; не гарантирует независимо подтверждённое время приёма. |

## Табло
| Элемент | Смысл |
|---|---|
| Ближайший приём | Следующий запланированный по расписанию приём. |
| Просрочено / опоздание | Расчётное время прошло без соответствующей своевременной отметки; не является медицинским диагнозом. |
| Предупреждение | Информационное сообщение о состоянии расписания или записи; не заменяет консультацию специалиста. |
| Обновить | Обновляет представление доступных данных; не создаёт отметку «Принято». |

## Архив и история
| Действие / понятие | Смысл |
|---|---|
| Курс завершён | Плановый период и необходимые отметки завершены по правилам приложения. |
| Архив | Раздел завершённых курсов и связанных записей; перемещение не означает удаление истории. |
| История | Хронологический журнал событий и исправлений. |
| Принято / Не принято (фильтры) | Показывают соответствующие категории записей, не меняя сами записи. |
| Период | Ограничивает отображаемый временной диапазон истории. |
| Свернуть | Скрывает раскрытый блок интерфейса, не удаляя его данные. |
| Повтор курса | Повторение оформляется изменением даты курса в разделе «Ввод». В «Архиве» не должно быть отдельной команды «Повторить курс». |
| Перед последним «Принято» | Предупреждение о возможном завершении и автоматическом перемещении курса в архив. |

## Демо
- Демо предназначено для ознакомления с интерфейсом и последствиями действий на демонстрационных данных.
- Нажатие «Принято» в Демо должно объясняться как демонстрационная отметка, а не реальный приём.
- Демо не должно обещать медицинскую консультацию, назначение дозировки или независимое подтверждение факта приёма.
- Переход к покупке и регистрация не должны трактоваться как уже совершённая оплата.

## Правила перевода на остальные 94 языка
1. Переводить **смысл в контексте действия**, а не отдельное слово.
2. Не превращать статусы («Не принято») в указания («Не принимайте»).
3. Не смешивать количественное содержание препарата и количество на приём.
4. Не смешивать расчётное и фактическое время.
5. Не обещать успешное сохранение до подтверждения операции.
6. Не смешивать «Случайное нажатие» и «Ошибка».
7. Сохранять различие между демонстрационными и реальными данными.
8. Для каждого языка сопоставлять три вещи: название кнопки на экране, объяснение рядом с ней и результат её нажатия. Например, «Принято» должно означать отметку о состоявшемся приёме, а не команду принять препарат.
